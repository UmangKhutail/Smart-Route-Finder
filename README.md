# Smart Route Finder using Dijkstra's Algorithm

## Project Overview
Smart Route Finder is a Python-based DAA project that uses Dijkstra's Algorithm to find routes between two locations using OpenStreetMap.

## Features
- Shortest Distance Route
- Fewest Turns Route
- Avoid Highways Route
- Interactive map using Folium
- Distance, travel time, fuel consumption and fuel cost estimation
- Comparison of three routing strategies

## Technologies Used
- Python
- Dijkstra's Algorithm
- Streamlit
- OpenStreetMap
- OSRM Routing API
- Folium
- Requests

## Installation

Install the required libraries:

```bash
pip install streamlit folium requests streamlit-folium
```

## How to Run

```bash
streamlit run DAA_Project.py
```

## Algorithm
Dijkstra's Algorithm finds the minimum-cost path in a graph with non-negative edge weights.

**Time Complexity:** O((V + E) log V)

## Project Purpose
This project demonstrates the practical application of Data Structures and Algorithms (DAA) in real-world route optimization.
